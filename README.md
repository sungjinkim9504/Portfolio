# 김성진 포트폴리오

HTML · CSS · 자바스크립트로 직접 만든 한 페이지 포트폴리오 사이트입니다.

- 사이트: https://sungjinkim9504.github.io/Portfolio/
- 대표 프로젝트: [잼박스(JamBox)](https://github.com/MoonHakCheol/Neuromin-Jambox) — 모바일 앱 전담

## 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 자기소개, 기술 스택, 잼박스, 수업별 학습 내용, 연락처 |
| `css/style.css` | 화면 스타일 (휴대폰 화면 · 다크 모드 대응) |
| `js/main.js` | 수업 분야별 보기, 스크롤 위치에 맞춘 메뉴 강조 |
| `img/` | 아이콘, 앱 화면 캡처(`img/screens/`) |

## 내용 추가하는 법

`index.html` 안에 주석으로 표시해 둔 곳을 풀고 채우면 됩니다.

- 학과 · 학년
- 앱 화면 캡처 갤러리 (`img/screens/`에 이미지 넣기)
- PDF 포트폴리오 받기 버튼 (`files/portfolio.pdf`)
- 앞으로의 목표
