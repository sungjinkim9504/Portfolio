# 김성진 포트폴리오

HTML · CSS · 자바스크립트로 직접 만든 한 페이지 포트폴리오 사이트입니다.

- 사이트: https://sungjinkim9504.github.io/Portfolio/
- 대표 프로젝트: [잼박스(JamBox)](https://github.com/MoonHakCheol/Neuromin-Jambox) — 모바일 앱 전담

## 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | HOME(10초 소개) · 프로젝트 · 기술 스택(기술·쓴 곳·한 일·이유) · 소개(협업·활동·수업) · 연락처 |
| `jambox.html` | 잼박스 Case Study — 개요 · 내 역할 · 구조 · DB · API · 기술 결정 · 트러블슈팅 · 테스트·배포 · 회고 |
| `css/style.css` | 화면 스타일 (휴대폰 화면 · 다크 모드 대응) |
| `js/main.js` | 수업 분야별 보기, 스크롤 위치에 맞춘 메뉴 강조 |
| `img/` | 아이콘, 앱 화면 캡처(`img/screens/`), ERD |

## 작성 원칙

- 팀이 한 일과 내가 한 일을 나눠 적는다.
- 직접 측정·검증하지 않은 수치는 적지 않는다.
- 트러블슈팅은 증상 → 원인 → 결정 → 검증 순서로 쓴다.
