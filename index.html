2.3문제 해결 사례

Case 01

팁이 화면을 옮길 때마다 떠서 불편함

원인자동으로 열리는 팁을 끌 방법이 없었음

해결"하루 동안 보지 않기" 체크박스를 만들고 기기에 저장

Case 02

팀장의 로그인 API 변경 후 앱 빌드가 깨짐

원인내 정보 조회가 로그인 토큰으로 본인을 확인하는 방식으로 바뀜

해결모든 호출 부분을 토큰 방식으로 고치고, SNS 가입 대기 흐름을 추가

Case 03

웹 지도에 추천 장소가 안 보임

원인네이버 지도는 등록한 주소(포트 5080)에서만 인증됨

해결실행 포트를 5080으로 맞춤

Case 04

로그인과 데이터가 전부 안 됨

원인Supabase 무료 플랜 프로젝트가 일시 정지됨

해결도메인 조회로 원인을 찾고 팀장에게 복구를 요청한 뒤 API를 다시 점검

Case 05

윈도우용 앱이 실행되지 않음

원인화면 주소 목록(Routes) 형식을 찾지 못함

해결참조 설정을 고쳐 윈도우에서도 실행되게 함
